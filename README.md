# AWS High Availability Project

## Overview
A DevOps project demonstrating a highly available web application on AWS.

## AWS Services
- Amazon VPC
- Amazon EC2
- Application Load Balancer (ALB)
- Auto Scaling Group
- Route 53
- Amazon CloudWatch

## Objectives
- Distribute web traffic across multiple Availability Zones.
- Automatically replace unhealthy EC2 instances.
- Monitor infrastructure health and performance.
- Practice infrastructure deployment and Git version control.

## Project Status
Initial setup in progress.

## Cleanup
All AWS resources will be removed after testing to avoid unnecessary charges.
